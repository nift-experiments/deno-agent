# D4 authored corpus

All 330 published authored-family routes (327 Markdown, three MDX) match the frozen HTML bytes after Nift composition in both distinct source models. The human route registry preserves original source paths, layouts and frontmatter organization. Agent routes maintain HTML and explicit metadata/fragments. No routine Markdown renderer is used by the agent build.

Scaling exposed exactly one actual Vento expression: runtime/reference/node_apis.md requests [vto, md] and calls generateNodeCompatibility(). The adapter invokes that original source function for that exact marker and source only; unexpected engines/marker counts fail. It does not implement Vento generally. The complete real-source page is part of the 330-page byte parity gate.

Leading-slash page source paths are preserved, including inherited double-slash Markdown alternate links. The accounting report had intentionally normalized filesystem paths; those must not be substituted for runtime source-path semantics. Existing duplicate IDs and link quirks remain unchanged.

Publication currently contains the 330 authored-family HTML routes only. D5 restores all generated families and completes assets/downloads/search/redirects/llms/HTTP behavior. Full publication, browser revalidation and benchmarks remain outstanding.
