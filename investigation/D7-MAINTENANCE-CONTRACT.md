# Agent maintained-source contract

The maintained page body is HTML. Route/title/original-route bindings are explicit in data/routes.json; five maintained templates/navigation/*.html variants recover the common main navigation. Full source prefix/suffix fragments retain page-specific heads, sidebars and layout details. Composition replaces the explicit main-navigation marker and binds edited titles/canonical routes without a Markdown/MDX/JSX content renderer.

Markdown downloads and search/LLM projections are maintained ancillary sources, not site renderer inputs. A content-maintenance transaction edits HTML and its associated exports/ and data/publication/ projections together. projection_body_sha256 acknowledges that the projection update has been reviewed; builds reject a changed HTML body without that acknowledgement. This guard is not a semantic proof that arbitrary coordinated edits are correct. Editors must inspect search content, full/summary metadata and LLM projections as part of maintenance. A transaction authoring helper may assist, but its work is not a routine site rendering stage.

Route addition registers a row, HTML and applicable projections/navigation. Rename updates the route row, canonical binding, navigation links and associated projection URLs/download path. Deletion removes its row and ancillary maintained records/links. The builder retires owned HTML, image and declared download outputs through its ledgers. data/download-ownership.json records original route-associated downloads; non-route static Markdown assets remain independent. Add new declared downloads to the ownership inventory too.

This model deliberately trades authoring transformations for explicit projection maintenance. The lifecycle measurements include complete publication from coordinated source changes; authoring/editing time is outside the timed build interval, as it is for the Markdown model. The final assessment must retain this maintenance burden and must not imply that changing one HTML file automatically regenerates a semantically complete search corpus or Markdown authoring representation.
